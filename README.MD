# Memory Game

Классическая игра «Найди пару» на чистом JavaScript.

## Описание

Игровое поле 4×4 с 16 карточками (8 пар). Игрок открывает по две карточки за ход: совпавшие пары остаются открытыми, несовпавшие закрываются через ~1 секунду. Игра заканчивается, когда найдены все пары — открывается модальное окно победы с итоговым числом ходов.

### Возможности

- Генерация интерфейса через `document.createElement`
- Автоматический старт игры при загрузке и перезагрузке страницы
- Случайное перемешивание карточек при каждой новой игре
- Счётчики ходов и найденных пар
- Таблица лидеров (топ-10) с сохранением в `localStorage`
- Модальные окна победы и лидеров
- Кнопки «Новая игра» (в хедере и в окне победы)

## Технологии

- CSS
- Vanilla TS (без библиотек и фреймворков)
